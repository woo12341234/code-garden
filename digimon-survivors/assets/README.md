# 스프라이트

모든 이미지는 `../tools/gen_sprites.py`로 생성한 오리지널 도트 그림입니다.
같은 파일명으로 다른 PNG를 덮어쓰면 게임에 그대로 적용되고, 파일을 지우면 색깔 원 + 이모지로 대체 표시됩니다.
(정사각형, 배경 투명, 그림이 가운데 오도록 넣어주세요. 플레이어 이미지는 왼쪽을 바라보게 그리면 이동 방향에 맞춰 뒤집힙니다.)
