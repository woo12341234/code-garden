# 스프라이트 교체 방법

이 폴더에 아래 파일명으로 PNG(정사각형, 배경 투명 권장)를 넣으면 게임이 자동으로 불러다 씁니다.
파일이 없으면 색상 원 + 이모지로 대체 표시됩니다.

| 파일명 | 용도 |
| --- | --- |
| `player.png` | 플레이어 |
| `baby.png` | 초반 잡몹 (예: 아구몬 이전 단계 이미지) |
| `rookie.png` | 중반 적 (예: 성장형 디지몬) |
| `champion.png` | 보스급 적 (예: 완전체 디지몬) |
| `bolt.png` | 주 무기 투사체 |
| `orbit.png` | 주위를 도는 보조 무기 |
| `gem.png` | 경험치 젬 |

개인용 게임이므로 소장한 이미지나 직접 그린 팬아트를 넣어 쓰세요. 배포용으로 공개할 계획이면
저작권이 없는 오리지널 아트로 바꾸는 걸 권장합니다.
