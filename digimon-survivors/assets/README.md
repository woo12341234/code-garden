## 문파

운학(무당파), 철산(소림사), 설아(북해빙궁), 천마(마교)와 새 문파 협객은 자기 문파 무공 2개를 레벨업 카드로 받을 수 있고,
둘 다 최대 단계가 되면 숨겨진 문파 오의로 합성됩니다.

## 경지 · 직위

무공 단계 합 + 오의 1개당 4 + 심법 2개당 1 이 수련도가 되어, 일정 이상이면 경지가 올라갑니다.
삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경.
경지가 오를 때마다 피해 +6%, 최대 HP +10, HP 전부 회복, 기운(오라) 색이 바뀌고 몸집이 조금씩 커집니다.
직위는 문파마다 다릅니다(예: 화산파 삼대제자 → … → 화산검선, 무림맹 맹원 → … → 무림맹주).

## 로그라이크 요소

- **수련장**: 판마다 모은 은자로 영구 강화(피해·HP·회복·속도·행운·재물운·다시뽑기·넘기기·봉인·환생·마기). 언제든 초기화해서 돌려받을 수 있어요.
- **레벨업 도구**: 다시뽑기 [R] · 넘기기 [X] (은자 +3) · 봉인 [B] (고른 카드가 이번 판에 다시 안 나옴).
- **정예 요괴**: 1:30부터 가끔 금빛 테두리의 강한 요괴가 나오고, 보물함을 떨어뜨려요.
- **백귀야행**: 7:00, 12:00, 이후 5분마다 요괴 행렬이 화면을 가로질러요.
- **장(챕터)**: 1장 마을 어귀 → 2장 대나무 숲 → 3장 버려진 산사 → 4장 저승길. 장마다 3:30 버티면 장의 주인(보스)이 나오고, 쓰러뜨리면 돌파 보상(선물 3개·은자·HP 회복) 후 다음 장으로 갈지 귀환할지 골라요. 4장의 저승사자를 쓰러뜨리면 퇴치 완료, 이후 무한 수련 가능.
- **Esc / P**: 일시정지 메뉴(빌드·무공별 피해 확인, 로비로 나가기).

## 아이콘

`icons/` 폴더의 테두리 달린 픽셀 아이콘은 `../tools/gen_icons.py`로 만들어요(메뉴·카드·HUD·업적의 이모지를 대신함).
`icons/map.txt`에 이모지 ↔ 파일 이름 대응표가 있어요.
무공마다 전용 아이콘 `icons/w_<무공id>.png`이 있고, 합성·오의로 완성되면 금테 붉은 배지 `icons/e_<무공id>.png`로 바뀌어요.

요괴 그림은 `../tools/gen_yokai.py`(무섭고 날카로운 화풍)로 다시 그려요. `gen_sprites.py` → `gen_heroes.py` → `gen_yokai.py` 순서로 실행하세요.

## 근접 기본기와 경지

검술과 권법은 처음엔 눈앞만 치는 근접 무공이지만, 경지가 오를수록 형이 바뀌며 멀리 닿아요(무협 장르의 흔한 성장 단계).

- 검술: 검술(삼류) → 검기(일류, 범위 확대) → 검사(절정, 가는 실 검기) → 검강(초절정, 꿰뚫는 초승달) → 이기어검(현경, 날아다니는 검)
- 권법: 권각(삼류) → 권풍(일류, 주먹 바람) → 권강(초절정, 꿰뚫는 권강) → 백보신권(화경, 먼 요괴에게 닿아 폭발)
- 합성: 검술 + 급소 찌르기 → 심검합일, 권법 + 금강불괴 → 금강패권 (한 단계 높은 형으로 펼침)

## 난이도 · 오의 연출

- 출정할 때 난이도를 골라요: 입문(요괴 ×0.6, 은자 ×0.7) · 강호(기본) · 고수(체력 ×1.5, 은자 ×1.5) · 마경(체력 ×2.4, 은자 ×2.5).
- 합성/문파 오의로 완성된 무공은 전용 색과 연출로 바뀌어요(두꺼운 겹 광선, 먹물 붓 고리, 큰 오의 문양, 빛나는 투사체, 먹물 튀김).

## 대시 · 필살기 · 비전서 · 숙련도 · 의뢰

- **경공 대시** (Space/Shift, 화면 버튼): 짧게 순간이동하며 무적, 2.4초 대기.
- **필살기** (Q, 화면 버튼): 처치·시간으로 게이지가 차면 협객마다 이름이 다른 필살기. 검(사방 검강) · 쌍검(X자 광선) · 장법(거대 손바닥) · 술법(진법 장판) · 암기(36발 사방) · 봉(회전 폭풍).
- **비전서**: 판 시작과 장 돌파 때 1권 선택. 뇌정·혈우·금강신체·연환·역천·만류귀종·탐욕의 길·흡성·천벌·유성검우·빙결지체·질풍·귀문·쌍천.
- **협객 숙련도**: 판이 끝날 때 숙련 경험치. Lv.1 HP +15 → Lv.2 시작 무공 +1단계 → Lv.3 피해 +8% → Lv.4 비전서 선택지 +1 → Lv.5 필살기 게이지 절반 시작·필살기 피해 +50%.
- **오늘의 의뢰**: 로비의 「의뢰」. 매일 3개, 한 판 안에서 달성하면 은자 지급.
